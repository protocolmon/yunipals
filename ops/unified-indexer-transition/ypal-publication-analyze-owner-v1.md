# One timed plan for the genuine publication query

This operator is inert by default. Root may invoke `--run` once on `yunipals-main` under the exclusive `/var/backups/yunipals-root-publication-analyze-20261026-1` audit. It reuses authenticated compiler utility `eaee00ac` and actual nonexecuting EXPLAIN receipt `fd53eb60`. Fresh compilation must reproduce the exact 3558-byte query `c2cce90a` and 3133-byte relation `bc47f8a5`, including the original count/probe wrapper and every official predicate. No Host, worker, pool, Source or current context is constructed.

One original postgres peer connects to the fixed Unix socket, `yunipals_backfill` OID17584, using the original UID111/GID113, clear environment and 60-second statement, 1-second lock, 72-second idle-transaction and 80-second parent limits. The transaction is `BEGIN READ ONLY`, original local search path, identity/settings queries, `EXPLAIN (ANALYZE TRUE,BUFFERS TRUE,VERBOSE TRUE,COSTS TRUE,SETTINGS TRUE,SUMMARY TRUE,FORMAT JSON)` over the unchanged SELECT, then `ROLLBACK`. Unlike the accepted predecessor, this diagnostic executes the query. It sets neither JIT nor work_mem; actual settings must equal the predecessor, including JIT on. A mismatch produces no accepted result. The 140-second outer diagnostic alarm changes no individual query timeout. There is no retry.

The full plan, including raw filters, expressions, outputs and worker details, is first saved privately as `full-plan.private.json` with mode0600. Public output is a bounded projection of at most 5000 nodes and depth128: path and parent path, parent relationship/subplan, node/join type, schema/relation/alias/index/scan direction, estimated rows/width/costs, actual per-loop rows/times and loops, and present buffer/I/O/selected memory or removed-row scalars. Missing buffer fields remain missing. Names require both a fixed public allowlist and an identifier pattern; unknown names are represented by SHA256. Known generated InitPlan/SubPlan labels retain only planner slot numbers. Index names are limited to the already public predecessor list and the known historical canonical-event ordering index. No raw SQL, filter, expression constant or application data row appears in the public projection.

Node times include child work, can overlap, and are per-loop averages; summing node times does not yield query elapsed time. Parallel worker details remain private. Buffer counters are blocks, not inferred bytes. JIT and top-level planning/execution milliseconds are separate. FunctionScan/Result nodes may hide expensive internal SQL-function work; this diagnostic does not claim to expose those internal plans. Planning and node instrumentation add overhead, so its times are not a causal comparison with an earlier plain SELECT or a qualification that a callback fits its original deadline.

Compiler/template/peer sources and private selector environment receive the same fresh hash/inode bookends as utility `eaee`; their values are not exported. The accepted EXPLAIN and utility hashes are rechecked. A completed plan grants no current, readiness, Source, held, prepared-ACK, timing or mutation authority. No persistent setting, index, schema, grant, service, input or existing receipt changes. Failure keeps its new audit and cannot authorize another attempt.
