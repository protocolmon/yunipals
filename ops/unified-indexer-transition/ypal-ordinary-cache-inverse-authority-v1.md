# Inverse-only cache authority

This new component accepts the completed Reader5 operation and the distinct
metadata inverse2 acknowledgement. It keeps the original CONT5 cache input,
SQL entry, component, private journals, old stopped worker, archived boot inode
and aborted XID16540148 as immutable ancestry. No actual input or receipt is
included in this source packet.

The private input is
`/var/backups/yunipals-ypal-ordinary-cache-inverse-authority-input-v1-20261026/input.json`.
Its exact fields are `format`, `readerRefs` and `metadataRestoredRefs`.
`format` is `yunipals-ypal-ordinary-cache-inverse-authority-v1-input`.
`readerRefs` contains the actual Reader5 result, producer and manifest SHA256s.
`metadataRestoredRefs` contains `mode: restored` and the actual inverse2 result,
input, producer and manifest SHA256s. Unknown fields are refused.

`Context(input_sha).bind(cache, host)` accepts the actual restored bridge's
cache and Host after their complete original constructors. The original
read-only inspect gate needs no forward approval. Binding must precede inverse
dispatch and cannot be repeated or moved to another Host. The component checks
the actual input, pure Reader5 acknowledgement, operation and cropped forward
metadata binding. It authenticates reconciliation80f4 through the new inverse
acknowledgement's `upgradeRefs`; it never passes restored references to the
forward CONT5 reconciliation predicate.

The isolated C413 namespace has this component's producer, format, source
manifest and audit domain. The actual cache and coordinated Reader5 journals
remain in their original domains. One retained inverse-descriptor constant is
corrected from the unused `continue-v5-20261025` reader path to the actual
Reader5 `continue-v5-20261026` path. Its bytecode, remaining constants, names,
defaults and closure remain unchanged. Published CONT5 files are untouched.

The complete original stopped, old-aborted transaction, inverse intent,
committed/prepared authorization, all-role APP inventory and positive kernel

authenticated new backend. The original zero-session predicate is not claimed

Its original dependency preauthorization, protocol deadlines and five-second
