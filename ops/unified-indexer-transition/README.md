This directory contains external operator helpers for the explicitly reviewed artifact2 transition. It is outside the frozen source/runtime payload. No helper in this directory installs an artifact, upgrades a proxy, changes a source selector, renews a paid replay permit, edits native metadata, resets a schema, or starts Solana.

Dev mode, a live role backend, a fresh native lock, a different build, or changed origin refuses startup. Only `.ponder` and the generated declaration are writable by the source user.
