healthy legacy collection reads and actual registry typeCount=0; the expected
JSON booster_index_unavailable/503 may remain visible as a catching-up state.
This supersedes the earlier full booster API-health publication gate.

fallback (try_files $uri /index.html). Do not include $uri/: the artifact's real
boosters/ asset directory otherwise redirects the /boosters SPA route to a
directory listing and a 403. Do not cache index.html or the setup bundle
across the change. The app's /collection path redirects to the collection root.
After publication, verify actual public collection/API/art reads and wallet UI.
Before owner activation/opening instructions, require healthy booster types and
owner endpoints. The owner must still sign the real setup calls, open the
capped pack, and observe actual Chainlink fulfillment before public pack sales.
