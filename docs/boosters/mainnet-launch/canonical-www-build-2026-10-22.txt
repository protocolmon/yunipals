Canonical www builds

The canonical Vercel project uses apps/yunipals-home-web as its root. Its checked-in
vercel.json runs `pnpm build:www --mode vercel-cloud` and clears the old dist output
override. Cloud mode writes the curated Build Output API tree to the app root's
.vercel/output, including the same asset cache rules, missing-asset 404 rules and
SPA fallback as the reviewed local prebuilt artifact.

The canonical build preserves all existing collection, leaderboard, Arena,
Islands/staking and Exomon routes and production feature/service settings. It
adds the deployed Base booster addresses and both reviewed setup bundle hashes.
It always invokes the full-app build mode; the temporary collection-only smoke
preset must never be used for the canonical site. These public launch values
do not depend on someone manually recreating Vercel environment variables. The
existing public Reown project configuration remains subject to the normal Vite
production check; no credential is added to the source.

From the app directory:

  pnpm build:www --mode vercel-cloud

The existing local prebuilt command retains its repository-root .vercel/output:

  pnpm build:www

Generic self-hosted builds remain available with the unchanged `pnpm build`
script (`vite build`); this Vercel setting does not replace that command.

Both canonical modes use a fresh /tmp release and copy only compiled assets plus
the explicit public allowlist. They never copy the complete prototype/public
media directory. Existing local artifacts are retained under a timestamped name.

The curated build supplies a non-VITE, build-only YUNIPALS_LICENSE_OUTPUT path so
the existing license plugin emits THIRD_PARTY_LICENSES.txt directly into that
fresh release. It checks the notice is present and nonempty before recording the
release manifest. No previous dist tree or license file is read. Generic builds
retain the plugin's original dist/THIRD_PARTY_LICENSES.txt default.

Build Output API reference: https://vercel.com/docs/build-output-api
Checked-in build/output overrides: https://vercel.com/docs/project-configuration/vercel-json

This change prepares future source-driven builds. It does not deploy or promote
another application version, change project environment settings, or change the
already accepted live artifact.
