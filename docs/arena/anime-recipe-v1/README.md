# Anime fighter recipe v1

`recipe-lock.json` commits to the exact bytes of `style.json` and `board.png`.
The board uses the existing reviewed prototype's four idle images as style references.
Those historical Ethereum fighters are regression fixtures, not approved Base fighters.

Generate idle first, explicitly review it, then generate the remaining poses using the
approved idle. The studio produces nine images (both dodge and dash are retained to
make the nine-image requirement explicit). Review the actual anatomy and locomotion;
species defaults never constitute approval. The export commits to five current Base
traits, the original artwork, all sprites, identity and recipe.

A curator note is public and limited to 140 UTF-8 bytes. A new recipe requires a new
version and lock; existing approved fighters retain their committed recipe.

The official Codex documentation supports scripted `codex exec` usage:
https://learn.chatgpt.com/docs/non-interactive-mode . This establishes the CLI workflow,
not an account-specific legal determination. The plan's commercial image/subscription
terms review remains a pre-launch item; no compliance clearance is asserted here.
