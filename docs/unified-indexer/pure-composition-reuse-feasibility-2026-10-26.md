The most conservative initial seam is the first site's **expected definition signatures only**. Its inputs are pure code bytes and parser/signature policy; the signature values are immutable strings. A bounded, exact-byte-keyed entry can retain a private tuple of name/signature pairs and return a new dictionary. All protected reads and original expected file-digest checks must run before lookup. The caller still creates a fresh AST, executes every existing transformation/count check, fixes locations, compiles, executes into new globals and performs every live predicate. Fresh dictionaries must not share a mutable cached map. No digest-only, path, inode, mtime or function-identity lookup can substitute for freshly supplied byte equality.

There is an important eligibility boundary: the existing generic factory accepts an opaque `transform` callback. A cache cannot assume an arbitrary callback is pure, or skip its side effects and caller-owned counters. The raw definition signatures are recorded before each node's transform in the current algorithm. Initial reuse should be restricted to exact authenticated constant/override-only call sites, or explicitly reviewed fixed transforms proven not to mutate an unvisited definition. Unknown callbacks or changed static inputs must follow the original computation. A generic mutable-AST memo would not meet that condition.

For any broader compiled artifact, exact input equality must cover **all** deterministic compilation inputs: fresh template bytes; transformation-producer bytes and a finite rewrite descriptor; all typed constant values, override names and required seam counts; output filename; selected definitions; parse mode/options; Python implementation/version; and explicit compiler future flags, optimization level and inheritance policy. Mutable function/global/closure objects are never cache keys or values. Default compile inheritance must match the original call site; the earlier compile-observer experiment showed that inserting a wrapper can change future-flag semantics. No global compile hook is proposed here.

On a code-artifact hit, `exec` must still run once in a newly allocated globals dictionary with the actual current overrides. Function defaults, annotations, module-level initialization and closures must be recreated by that execution, not retained from a previous context. Code objects may be immutable; their function objects, namespaces, captured `Context`, epoch, Host, callbacks, sessions, source proofs and catalogs are not. All existing expected-code comparisons and fresh ownership/dispatch predicates remain. A failed compile, transform, guard or live execution is never cached or converted into success. Finite optional cache failure must fall back without replaying a completed original operation; TimeoutError, cancellation and external deadlines propagate.

This assessment identifies a concrete pure descriptor seam, but does not yet prove worthwhile unprofiled savings or a safe adoption route. The initial signature-only seam removes serialization/hash computation, not AST fixing, compilation or execution. The smaller observer/worker descriptors may be cheap individually. The structural node counts and heavily distorted local profile cannot justify a claimed production saving. The recorded evidence is sufficient to design a bounded local equivalence experiment over these exact public inputs, not to bypass a current check or install a production cache.

An eventual implementation would need an honest separately reviewed producer/seam rather than patching frozen owner/factory globals and claiming the old producer passed unchanged. Required controls include fresh equal-but-distinct source bytes; changed bytes under unchanged file metadata; changed rewrite inputs/filename/compiler flags; unknown callbacks; cross-call namespace/global/default/container independence; exact original code/signature/line/exception fields; and original errors/cancellation without replay. No production helper, additional Source/Host current call, database work, SSH, runtime operator or new held/commit authority is part of this document.
