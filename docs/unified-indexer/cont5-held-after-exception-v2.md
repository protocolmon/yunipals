# CONT5 post-failure witness for the actual authority facade

This helper is source-only and inert by default. It invokes no current/source,
database, callback, transport, approval refresh or service action. It installs
no tracer, profiler, wrapper or retry. The original failure and frozen witness1
`ba7e2570…` remain unchanged.

The actual HELD7 witness refusal exposed a concrete object distinction.
`ypal-ordinary-cache-continuation-context-v1.py:authority()` returns the loaded
Auth5 module. That thin module's `__getattr__` delegates functions to
`composition()`. Therefore the actual cache's `continuation_authority` object
is the facade while `_qualify_held.__globals__` belongs to its composed module.
Witness1 required those two dictionaries to be identical. Earlier factory
fixtures returned a flattened authority and missed this production shape.
The new tests reproduce the old refusal without changing facade, factory,
utility or composition bodies.

`Witness(original_error, actual_cache.continuation_authority).snapshot()` is
the same finite API. The new producer is
`yunipals-ypal-cont5-held-after-exception-v2`. It authenticates witness1 and its
21 pinned authority/source-manifest prerequisites before evaluating the retained
helper. The existing complete CONT5 source graph is also required for genuine
static authority composition; this package does not create or replace that
graph, any private input, or any receipt.

The new constructor derives witness1's complete constructor from its exact
frozen source. It counts two `authority.__dict__` comparisons and redirects
only those comparisons to the authenticated composed namespace. It inserts one
explicit facade-resolution call. All original complete qualifier/wrapper code
checks, namespace identities, bounded traceback traversal, exact frame-code
identity, and original cache-authority object comparison remain active. The
cache is never replaced or relabelled as the composed module.

For a facade, the resolver requires its exact fixed source path, identity
globals, source pins, and complete function bodies/defaults/closures. Every
function must use the actual facade globals. Its `composition()` result must
be the actual `_implementation`; the exported qualifier functions must be
those same functions in that implementation. The exact current implementation's
code and globals must match the actual unwound frame. A changed implementation
cannot cause an earlier frame's inner error to be adopted. The original direct
composed-namespace route also retains its original complete checks.

Snapshot output has its own v2 format, records whether the facade route was
used, and states `originalV1WitnessPassed: false`. It retains the same original
inner exception object and private rendered traceback when an exact frame
contains that exception. Unknown frames and a genuine qualifier without an
inner exception remain explicit absence. It grants no timing, source, metadata
or transaction-outcome authority, and performs no receipt write. The private
snapshot must not be exported as raw user-facing output.

The root driver must call this helper only after the original exception has
reached its handler. Diagnostic authentication, snapshot or private-write
failure must never replace the original operation error or its saved traceback.
This source cannot recover a discarded Python exception object from the already
terminated HELD7 process. HELD7's actual failure, independent PostgreSQL log
evidence and catalog reconciliation remain separate history.

Run the co-located controls with:

```sh
python3 -I -B ops/unified-indexer-transition/ypal-cont5-held-after-exception-v2.test.py
```

composition bodies, and genuine C5 rollback-transport/prepared-callback

refusal and verify v2's same-object inner-error recovery; direct namespace
support; exact facade/function/source/cache binding refusals; no adoption after
implementation change; explicit missing-inner/unknown-frame output; preserved
existing observer state; and no business or transport reentry. They execute no
production driver, SQL child or service action and claim no successful held

five-second reserve and dependency deadline are unchanged.
