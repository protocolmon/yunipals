# Serum bottle artwork

Approved soft 3D Yunipals catalogue illustration, generated with the built-in
image generation tool. `catalogue.webp` preserves the complete review sheet.
The numbered WebP files are thumbnail crops, not independently generated
high-resolution illustrations. Keep them at thumbnail scale in the interface.
Backgrounds are intentionally retained; these are not transparent cutouts.

Artwork version: 1. Catalogue version: 1.

IDs match `packages/yunipals-market-core/src/serums.ts`:
`id = essenceIndex * 11 + formIndex + 1` (zero-based indexes).
The sheet has essences across columns and forms down rows. Do not interpret
the sheet as row-major serum IDs. Presence, rarity and card finish must come
from game data, never from the bottle image.

Source illustration: 1285 × 1224 pixels. Crops were encoded as WebP at quality
90 without upscaling. Column boundaries: 120, 224, 328, 433, 538, 643, 748,
853, 958, 1063, 1168, 1276; inset each column by 2 pixels on each side.
Row bounds (top inclusive, bottom exclusive): 151–236, 240–325, 330–413,
418–502, 508–587, 593–666, 672–742, 748–822, 828–904, 902–991, 996–1157.

Art direction: rounded thick glass, candy-colored liquid, chunky sculpted
details, soft dimensional shading and gentle lighting, using the base
Yunidragon card as the style reference. Preserve each Essence's color/material
identity and each Form's silhouette. Avatar combines crown, wings, scales and
claws. No faces, fine metal filigree or encoded Presence. This art represents
the serum item and is separate from generated transformed Yunipal artwork.
